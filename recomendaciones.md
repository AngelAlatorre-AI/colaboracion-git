# Recomendaciones para trabajar con Git
En este archivo se documentarán buenas prácticas para trabajar con repositorios.
## Recomendaciones iniciales
- Utilizar mensajes de commit claros.
- Revisar los archivos modificados antes de crear un commit.
- Evitar subir archivos innecesarios al repositorio.
## Nuevas recomendaciones
Los colaboradores deberán agregar recomendaciones adicionales.
- Leer primero el README.md antes de iniciar cualquier  cambio.
