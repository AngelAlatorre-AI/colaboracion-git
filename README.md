# Guía colaborativa de Git y GitHub
Este repositorio fue creado como parte de una práctica de colaboración utilizando Git y GitHub.
## Objetivo
Construir de manera colaborativa una pequeña guía con comandos, recomendaciones y recursos
relacionados con Git y GitHub.
## Flujo de colaboración
Fork → Clone → Cambios → Commit → Push → Pull Request → Merge → Sincronización
